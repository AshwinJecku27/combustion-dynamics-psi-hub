# data/ (intentionally empty in this handoff)

The source NASA PSI files used to build the dashboard were uploaded to the original Claude session and are NOT included here.
Re-download them from the NASA Physical Sciences Informatics (PSI) repository (https://www.nasa.gov/psi) and place them in this folder
if you want to re-derive or verify the embedded arrays. See HANDOFF.md sections 4 and 10 for the exact file names and the procedure for adding files without silently changing existing records.
Check each file's licence/terms before committing it to a public repository.
